## Сильные стороны

- **Полноценный CRUD** для товаров в админ-панели (создание, чтение, редактирование, удаление с подтверждением)

- **6 Mongoose-моделей** с TypeScript-интерфейсами и timestamps

## Критические проблемы (блокируют зачёт)

### 1. Отсутствие JWT-авторизации
Пакет `jsonwebtoken` не установлен. Токены не генерируются и не проверяются. Все API-эндпоинты (включая административные) полностью открыты. Авторизация существует только на уровне фронтенда (хранение user-объекта в localStorage), что не обеспечивает реальную безопасность.

**Затронутые критерии:** FE05 (5/10), BE03 (2/10), BE04 (3/10)

### 2. Отсутствие кастомных middleware
Нет ни одного кастомного Express middleware — ни auth, ни validation, ни role-checking. Глобальный error handler содержит баг (параметр `_res`, но используется `res`).

**Затронутые критерии:** BE03 (2/10)

### 3. Отсутствие кастомных хуков
Ни одного `useXxx` хука. Паттерн загрузки данных (useState + useEffect + try/catch) скопирован в 7+ компонентах. Нет типизированных Redux-хуков.

**Затронутые критерии:** FE08 (2/10)

## Рекомендации для доработки

### Приоритет 1 (обязательно для зачёта):
1. **Установить и настроить JWT** — `npm install jsonwebtoken @types/jsonwebtoken`, генерировать токен при логине, возвращать клиенту
2. **Создать auth middleware** — проверка Bearer-токена на защищённых маршрутах
3. **Создать role middleware** — проверка роли admin на административных эндпоинтах
4. **Отправлять токен с фронтенда** — добавить заголовок `Authorization: Bearer` во все API-запросы
5. **Создать минимум 2-3 кастомных хука** — `useAppSelector`/`useAppDispatch` (типизированные), `useFetch` (унифицированная загрузка данных)

### Приоритет 2 (улучшит оценку):
6. Добавить страницу 404 (fallback route)
7. Заменить `alert()` на toast-уведомления
8. Вынести дублирующиеся интерфейсы и функцию `generateProducts` в общий модуль
9. Добавить клиентскую валидацию в форму регистрации
10. Разбить монолитные компоненты AdminPage (569 строк) и AccountPage (416 строк)
11. Исправить баг в глобальном error handler (`_res` → `res`)
12. Добавить PUT/PATCH/DELETE эндпоинты для всех сущностей
