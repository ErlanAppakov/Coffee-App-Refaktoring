# FE07: Переиспользуемые компоненты

## Оценка: 4/10

## Чеклист

- [ ] Компоненты разбиты на мелкие, переиспользуемые части
- [ ] Props используются для настройки поведения
- [ ] Компоненты не содержат бизнес-логику (презентационные)
- [ ] Есть UI-компоненты (Button, Input, Modal, Card и т.д.)
- [x] Компоненты используются в нескольких местах
- [x] Children/render props/composition (если применимо)

## Что реализовано хорошо

- Компоненты `Logo` и `Menu` переиспользуются в Header и Footer -- классический пример композиции
- `NewsList` является чистым презентационным компонентом с типизированными props (`image`, `title`, `subtitle`) и используется 4 раза в `News`
- `PrivateRoute` и `AdminRoute` корректно используют паттерн `children: ReactNode` для композиции маршрутов
- Существует отдельный `ProductCard` в `components/product-card/` с типизированным интерфейсом `ProductCardProps`
- Страничные секции (Hero, Benefits, CatalogHomePage, News) вынесены из HomePage в отдельные компоненты, что улучшает читаемость

## Что нужно улучшить

- **Дублирование ProductCard:** В проекте существуют два разных компонента ProductCard -- один в `components/product-card/product-card.tsx`, другой локально в `pages/products-page/products.tsx`. Кроме того, `DiscountSection` полностью дублирует разметку карточки товара вместо использования любого из существующих ProductCard. Три места с одинаковой разметкой (звёзды, изображение, цена, кнопка) -- прямое нарушение DRY
- **Отсутствуют базовые UI-компоненты:** Нет переиспользуемых `Button`, `Input`, `Card`, `Loader` и т.д. Кнопки и инпуты дублируются на каждой странице с инлайн-стилями или разными CSS-классами. Например, кнопки "В корзину", "Подписаться", "Оплатить заказ" -- все написаны заново
- **Modal содержит тяжёлую бизнес-логику:** Компонент `Modal` не является переиспользуемым -- он жёстко привязан к формам регистрации/логина, содержит вызовы Redux dispatch, навигацию, управление формой. Нет возможности использовать модальное окно для других целей (подтверждение удаления, информационные сообщения)
- **AccountPage содержит встроенную модалку редактирования** (строки 307-413) -- огромный блок JSX внутри компонента страницы, вместо выделения в отдельный компонент EditProfileModal
- **AdminPage монолитная** (~570 строк) -- содержит таблицы, формы, модалки для товаров и пользователей в одном файле. Можно выделить ProductsTable, UsersTable, ProductForm, PasswordResetModal
- **ControlPanel** (~220 строк) содержит полную логику поиска с debounce, рендеринг результатов и обработку кликов -- можно выделить SearchBar в отдельный переиспользуемый компонент
- **Нет переиспользуемого Loader/Spinner:** Текст "Загрузка..." дублируется в Hero, CatalogHomePage, DiscountSection, Products, ProductDetail, BlogPage, Faq, AdminPage -- можно заменить единым компонентом
- **Props почти не используются для настройки поведения:** Большинство компонентов (Logo, Menu, Modal, Header, Footer, все секции HomePage) не принимают props вообще. Единственные компоненты с props для настройки -- NewsList и ProductCard
- **Функция `generateProducts` дублируется** целиком в `products.tsx` и `productDetail.tsx` (~70 строк копипасты) -- должна быть вынесена в утилиту
