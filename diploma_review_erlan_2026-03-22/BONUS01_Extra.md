## Что реализовано хорошо

- **Поиск по товарам** — полноценная реализация: debounce 300мс, выпадающий список результатов с изображениями и ценами, закрытие по клику вне области, отдельный Redux-слайс для состояния поиска, интеграция с навигацией (клик по результату ведёт на страницу товара)
- **Docker Compose** — грамотная конфигурация: MongoDB 7.0 с healthcheck, именованными volumes для персистентности данных, отдельной bridge-сетью, `.dockerignore` для оптимизации. Также подробная документация `MONGODB_SETUP.md` по настройке
- **README** — качественная документация: описание стека, пошаговая установка, структура проекта, описание скриптов, раздел troubleshooting, «быстрый старт», ссылки на дополнительные файлы. Backend также имеет отдельный README с описанием API endpoints
- **Система скидок** — многоуровневая накопительная система (10%/15%/20%) с отображением прогресса до следующего уровня в личном кабинете
- **Yandex Maps** — встроенная карта на странице контактов через iframe конструктора Yandex Maps
- **Swiper-слайдер** — Hero-секция на главной странице с пагинацией через библиотеку Swiper
- **Lazy loading** — атрибут `loading="lazy"` на изображениях в 10 файлах для оптимизации загрузки
- **Загрузка аватара** — пользователь может загрузить аватар профиля (валидация размера до 7MB, проверка типа файла, предпросмотр, конвертация в Base64)

## Что нужно улучшить

- **Docker** — контейнеризирована только MongoDB; отсутствует Dockerfile для frontend и backend, что не позволяет развернуть весь проект одной командой
- **Адаптивная вёрстка** — media queries реализованы только для сетки товаров и админ-панели; header, footer, корзина, личный кабинет и другие страницы не адаптированы
- **Отсутствует деплой** — проект не развёрнут на внешнем хостинге
- **Нет CI/CD** — отсутствуют GitHub Actions или аналогичные pipeline
- **SEO** — `index.html` минимален: нет meta description, Open Graph тегов, favicon подключены как `rel="stylesheet"` вместо `rel="icon"` (ошибка)
- **Пагинация** — реализована как «показать ещё» на клиенте, а не серверная пагинация с параметрами запроса
