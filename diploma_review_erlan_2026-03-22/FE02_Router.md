# FE02: React Router

## Оценка: 7/10

## Чеклист

- [x] Установлен react-router-dom (v7.9.1)
- [x] BrowserRouter обёртка в корне (main.tsx)
- [x] Несколько маршрутов (Route) — 8 маршрутов: `/`, `/blog`, `/contacts`, `/catalog/:category`, `/catalog/:category/:productId`, `/cart`, `/account`, `/admin`
- [x] Навигация через Link/NavLink (не `<a>`) — NavLink в меню, Link в логотипе, каталоге, корзине, карточках товаров
- [x] Динамические маршруты (/:id) — `/catalog/:category` и `/catalog/:category/:productId`
- [ ] Страница 404 / fallback route — отсутствует
- [x] Вложенные маршруты (nested routes) — Content содержит вложенный Routes внутри App
- [x] useNavigate/useParams/useLocation хуки — useNavigate (5 компонентов), useParams (3 компонента), Navigate (2 компонента)

## Что реализовано хорошо

- Грамотная структура маршрутизации: верхнеуровневые Routes в App.tsx делегируют публичные маршруты в Content, а защищённые маршруты (`/account`, `/admin`) обрабатываются отдельно
- Два уровня вложенности маршрутов через компонент Content, который содержит собственный блок `<Routes>`
- Динамические маршруты с двумя параметрами (`/catalog/:category/:productId`) — хороший паттерн для каталога товаров
- Активное использование хуков: useNavigate для программной навигации (после добавления в корзину, при авторизации), useParams для извлечения параметров из URL
- Навигация через NavLink в меню (даёт возможность стилизации активного элемента) и Link в остальных компонентах
- Защищённые маршруты реализованы через компоненты-обёртки PrivateRoute и AdminRoute с перенаправлением через `<Navigate>`
- AdminRoute имеет ролевую проверку — неадмин перенаправляется на `/account`, неавторизованный — на `/`

## Что нужно улучшить

- **Нет страницы 404 / fallback route** — при переходе на несуществующий URL пользователь увидит пустую страницу. Необходимо добавить `<Route path="*" element={<NotFoundPage />} />` в Content и/или в App
- **Использование `<a>` тегов для внутренней навигации** — в footer.tsx (`<a href="/">`), news-list.tsx (`<a href="/">`), news.tsx (`<a href="/">`) используются обычные якорные ссылки вместо `<Link>`, что вызывает полную перезагрузку страницы
- **Нет lazy loading (React.lazy + Suspense)** — все страницы загружаются синхронно в бандл. Для проекта с 8+ страницами стоит разделить код через `React.lazy()` и `<Suspense>`
- **Не используются useLocation и useSearchParams** — нет отслеживания текущего пути и работы с query-параметрами, что могло бы пригодиться для фильтрации в каталоге
- **useParams импортирован, но не используется** в `discount-section.tsx` — мёртвый импорт
- **Маршрут `/catalog` без параметра** — компонент BeanToCup содержит `<Link to='/catalog'>`, но такой маршрут не определён, что приведёт к пустой странице
